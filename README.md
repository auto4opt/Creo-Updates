# Creo Studio | OpenArm Edition

Official installer and signed update distribution. Source code is maintained in a separate private repository.

Download the installer for your platform from [the latest release](https://github.com/auto4opt/Creo-Updates/releases/latest).

Starting with 0.1.3, the desktop client checks for updates and asks before installing. Older clients need one manual upgrade. Update artifacts are cryptographically signed; no GitHub login or source repository access is required.

macOS installers are available for Apple Silicon and Intel. Windows and Linux packages will be listed only when built and validated. Linux in-app updates use AppImage; deb installations use package upgrades.
